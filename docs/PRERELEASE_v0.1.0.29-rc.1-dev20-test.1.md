# Naxxramas Loot Ledger — v0.1.0.29-rc.1-dev20

**Pre-release for World of Warcraft 3.3.5a (Interface 30300)**

## What's New

- **My Wishlist:** Cleaner layout, improved spacing and seven items per page.
- **Inbox:** Newer/Older pagination, plus Archive and Restore to organise submissions.
- **Award History:** Shows recorded roll winners and award attempts. New Run View lets you start a fresh display, while All History keeps earlier records accessible.
- **Gear Plans:** Improved character filtering, guarded edits and Import/Export with conflict review.
- **Molten Core Recipes:** Profession-requirement review for crafting recipes.
- **Loot Diagnostics:** New read-only loot-source and duplicate-item checks.

## How to Install

1. **Close World of Warcraft.** Back up your existing `Interface/AddOns/NaxxLootLottery` folder and `WTF/Account/<account>/SavedVariables/NaxxLootLottery.lua` (including `.lua.bak`, if present).
2. Under **Assets** below, download **`Naxxramas-Loot-Ledger-v0.1.0.29-rc.1-dev20.zip`**. Use the addon ZIP, **not** GitHub's automatic *Source code* ZIP.
3. Extract the ZIP and copy its **`NaxxLootLottery`** folder into `World of Warcraft/Interface/AddOns/`, replacing the previous addon folder. Leave your `WTF` SavedVariables untouched.
4. Launch WoW and type `/nll version` and `/nll status` to confirm **`0.1.0.29-rc.1-dev20`** and **READY**.
